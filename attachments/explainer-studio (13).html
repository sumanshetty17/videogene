How this works

This runs entirely on free tiers — no card on file anywhere. Your Worker proxies the analysis call and serves this page over https:// (required, since the narration engine refuses to run from a local file). Everything else — rendering, audio decoding, and video export — happens live in this browser tab.

Content analysis — your source text is sent through your Worker to Cloudflare Workers AI, which returns a full scene-by-scene lesson (narration + visual kind + real named entities) as JSON, classified using an explicit animation grammar so each concept gets the visual that actually explains it.
Animation — a renderer registry maps each scene's visual kind (physical mechanisms, circuits, waveforms, graphs, exploded/cross-section views, causal chains, concept maps, comparisons, timelines, equations) to a hand-coded canvas renderer, with camera moves and captions drawn directly onto the canvas.
Narration — real generated audio, fetched via Puter.js (a free, unlimited, no-signup TTS gateway) for each scene, using the voice you pick.
Export — the fetched audio buffer and the canvas animation (captions included) are routed into the same MediaRecorder via the Web Audio API, so the download always has narration baked in — no screen/tab-audio permission step involved. You can also regenerate a single scene without rebuilding the whole lesson.
For a production version at scale: move rendering to a server-side pipeline (e.g. Remotion/FFmpeg) with a job queue for longer documents, add Three.js/GLB for real 3D device models, and use object storage + a CDN for hosting finished videos — all of which move this beyond a single free Worker.
